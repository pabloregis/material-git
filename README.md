# Material do treinamento de Git

Material para os alunos do treinamento de Git e frontend.

| Arquivo | O que é | Abrir no navegador |
|---|---|---|
| `apostila.html` | Os exercícios passo a passo | [apostila](https://pabloregis.github.io/material-git/apostila.html) |
| `cola.html` | Referência rápida dos comandos, com a tradução | [cola](https://pabloregis.github.io/material-git/cola.html) |
| `apostila.pdf` | A apostila para imprimir ou ler sem internet | [PDF](https://pabloregis.github.io/material-git/apostila.pdf) |
| `slides.pdf` | Os slides da aula | [PDF](https://pabloregis.github.io/material-git/slides.pdf) |

Para baixar tudo, clique no botão verde **Code** (código) › **Download ZIP** (baixar ZIP), descompacte e dê dois cliques em `apostila.html` ou `cola.html`.
